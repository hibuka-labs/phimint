核心能力

不是补全一行代码，是帮你把任务做好

从一个需求到一版能用的改动，它自己跑完整条路。

天生就轻，就一个文件

Rust 编出来的单个静态二进制，零运行时依赖：不装 Node、不配 Python。SSH 到一台 1 核 1G 的裸服务器，curl 一行就是完整编码会话。

原生 LSP 快内环

按项目自动接上对应的语言服务（rust-analyzer / TypeScript / clangd…），改完立刻拿到行列级类型错误，不等重编译；tree-sitter 仓库地图 + ripgrep 按需取上下文，不整仓塞进对话。

CodeAct 跑机械活

批量改名、数据整理这类机械活写进一段 Python 一次跑完，顶掉一长串单点工具调用。会话常驻：变量、函数下次接着用，中间数据留在本地不进上下文——模型往返少了，token 省在这。没装 Python 也照用。

多 agent 并行

复杂问题拆成几路，派默认只读的调查员一起查（写能力按次申请）；报告在回合边界批量送到，不用轮询；任务面板逐个实时跟踪。

UI/产品设计支持

布局、方案对比这类取舍，候选并排摆进浏览器画布，你点一个，点击就是真实用户回合——agent 不替你拍板；概念问题在终端选择器里问（2–4 个候选）。

插件模式，一切皆插件

MCP 服务、用户脚本、wasm 插件包走同一套契约（WIT + Component Model）接入，加能力不用动主程序；/tools 列出每个工具的来源和权限档，一键关闭。

重活不将就，琐事不浪费

重活上 advanced、日常用 main、琐事丢 lite，三档还能各配各的厂商——便宜活不烧贵模型，成本自己拿捏。

权限边界清楚

auto / ask / deny 三档随时切，子 agent 跟随；shell 命令按风险分红黄绿，密钥只以 ${ENV:VAR} 引用落盘；能看屏幕、挪指针，但凡改机器每次都问。

定位

轻巧、稳定、长跑不臃肿

靠谱不光是活干得漂亮，还有连着干一下午也不掉链子：不卡、不崩、不越跑越臃肿。轻和稳是编译期锁住的——纯 Rust 实现。东西还是你的：模型你的，代码你的。

server|CI|container

苛刻环境也从容

Rust 编出来的独立二进制，丢进服务器、CI、容器这些苛刻点的环境就能跑，本身不吃多少资源。

no gc

不卡，也不崩

输入、滚动、逐 token 流式输出不卡帧，也没有 GC 停顿来打扰。内存和并发的低级错误，Rust 在编译期就替你清掉了，干活干到一半不掉链子。

no bloat

跑一下午，不臃肿

连着开几个小时、对着大仓库，内存占用稳得住，不越用越沉。

api_key

你的模型，你的代码

接你自己的 API key，换厂商只是改一行配置；代码和密钥都留在你的机器上，MIT 开源可自控。

常见问题

还有一点疑虑？

phimint 是什么？和我正在用的 AI 编程工具有什么不同？+
一个文件，跑通 AI 编码闭环。
Rust 写的终端 AI 编程智能体，不装 Node、不配 Python——1 核 1G 的裸服务器，一行 curl 就能开工。
关键决定都在你手里：布局和方案并排摆进浏览器画布，点一个才算数；模型分三档按需各配各的厂商，密钥只以引用落盘，代码和数据留在本地，MIT 开源。
我现有的 .claude/skills 技能还能用吗？+
能。.claude/skills 里的技能直接用，/skill-name args 即可调用——已有的技能资产原样复用，不用重写。
支持哪些模型？需要买专用订阅吗？+
不需要专用订阅。phimint 接你自己的 API key：OpenAI、Anthropic、DeepSeek、阿里云、Moonshot、Gemini、Ollama 本地模型等都支持。main / lite / advanced 三档可以分别配不同厂商的模型，按任务挑性价比。
收费吗？+
phimint 本身免费、开源（MIT）。你只需要为所选模型厂商的 API 用量付费（或用本地模型，那就是零成本）。没有隐藏订阅。
支持哪些平台？+
macOS、Linux、Windows。安装方式可选脚本、Homebrew、npm 或 cargo install phimint。国内用户推荐用 Gitee 镜像源的安装脚本。
怎么卸载？+
一条命令卸干净：phimint uninstall 会按当初装它的方式移走二进制，再删掉 ~/.phimint/——配置（含 API key）、会话、历史、笔记一起清掉。--keep-data 保留这个目录，--yes 跳过确认；Windows 上还会清掉安装脚本加的 PATH 条目。二进制已经不在了的话，手动删掉 ~/.phimint/ 就是全部数据。
我的代码和数据会被上传吗？+
不会。phimint 在你本机运行，配置和密钥存放在 ~/.phimint/。发往模型厂商的只有对话和工具结果（这由你选的模型厂商决定），phimint 自己不存你的代码、不做中转。对数据敏感的团队，可以配本地 Ollama 模型完全闭环。
可以为团队定制、私有化部署或提供技术支持吗？+
可以。phimint 是开源产品，团队有私有化部署、定制开发、接入集成或技术支持的需求，欢迎直接联系：phimint@hibuka.com，或页尾扫码进飞书群直接聊。
怎么参与贡献？+
欢迎提 Issue 和 PR：GitHub 与 Gitee 双仓库均开放。功能想法、bug 报告、文档改进都算贡献。
