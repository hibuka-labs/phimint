核心能力

不是补全一行代码，是把一个任务做完

从一个需求到一版能用的改动，它自己跑完整条路。

多 agent 协作

复杂问题派几个子 agent 分头调查，报告完整带回来。

给模型接上 LSP

按项目自动接上对应的语言服务（rust-analyzer / TypeScript / clangd…），改完立刻拿到类型错误——不用等重新编译，agent 自己看得见对错。

token 花在刀刃上

该搜才搜、该读才读，不把仓库塞进对话；费上下文的探查丢给分身，只把报告带回来；长任务快撑爆就换一窗接着干，笔记和交接自动带着走——不靠有损摘要，token 少烧一截。

不空转，不跑丢

空转了自己纠、到点自己收尾；厂商谎报截断也有守卫兜着——不瞎耗 token，活干到交卷。

重活不将就，琐事不浪费

重活上 advanced、日常用 main、琐事丢 lite，三档还能各配各的厂商——成本自己拿捏。

极致轻量，就一个文件

curl 一行拿到一个可执行文件——不用先装 Node、Python 这些 runtime，不带依赖；不想要了，删掉它就是卸载。

常见问题

还有一点疑虑？

phimint 是什么？和 Claude Code / codex 这类工具有什么不同？+
phimint 是一个开源的终端 AI 编程智能体，跑完整的编码闭环：理解需求、读代码、改多文件、编译测试、失败迭代。它的差异点在三处：多 agent 扇出 + 报告全文回注（不轮询、不丢结论）、三档审批（全自动 / 写操作需确认 / 只读，权限边界清晰）、模型与代码都不被绑定（接任意厂商的 API，MIT 开源可自控）。
我现有的 .claude/skills 技能还能用吗？+
能。.claude/skills 里的技能直接用，/skill-name args 即可调用——从 Claude Code 搬过来不用重写。
支持哪些模型？需要买专用订阅吗？+
不需要专用订阅。phimint 接你自己的 API key：OpenAI、Anthropic、DeepSeek、阿里云、Moonshot、Gemini、Ollama 本地模型等都支持。main / lite / advanced 三档可以分别配不同厂商的模型，按任务挑性价比。
收费吗？+
phimint 本身免费、开源（MIT）。你只需要为所选模型厂商的 API 用量付费（或用本地模型，那就是零成本）。没有隐藏订阅。
支持哪些平台？+
macOS、Linux、Windows。安装方式可选脚本、Homebrew、npm 或 cargo install phimint。国内用户推荐用 Gitee 镜像源的安装脚本。
我的代码和数据会被上传吗？+
不会。phimint 在你本机运行，配置和密钥存放在 ~/.phimint/。发往模型厂商的只有对话和工具结果（这由你选的模型厂商决定），phimint 自己不存你的代码、不做中转。对数据敏感的团队，可以配本地 Ollama 模型完全闭环。
界面支持中文吗？+
支持。会话标题跟随对话语言，中文对话体验是完整的一等公民。文档提供中英双语。
可以为团队定制、私有化部署或提供技术支持吗？+
可以。phimint 是开源产品，团队有私有化部署、定制开发、接入集成或技术支持的需求，欢迎直接联系：phimint@hibuka.com，或页尾扫码进飞书群直接聊。
怎么参与贡献？+
欢迎提 Issue 和 PR：GitHub 与 Gitee 双仓库均开放。功能想法、bug 报告、文档改进都算贡献。
