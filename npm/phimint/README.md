# phimint (npm)

Terminal AI coding agent built on [phi-agent](https://github.com/hibuka-labs/phi-agent).

## Install

```bash
npm install -g phimint      # or pnpm add -g phimint / yarn global add phimint
phimint
```

This package is a thin launcher: the binary itself ships in the matching
`phimint-{platform}` optional dependency (no postinstall scripts, works with
pnpm and registry mirrors out of the box).

## Upgrade

```bash
npm install -g phimint@latest
```

Other install channels and configuration: see the
[project README](https://github.com/hibuka-labs/phimint#readme).
